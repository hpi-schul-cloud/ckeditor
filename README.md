# CKEditor

Custom version of CKEditor5 for the Schulcloud-Verbund-Software-Client

## Install

```sh
npm i @hpi-schul-cloud/ckeditor
```

## Supported editor modes

- Classic Toolbar
- Balloon Toolbar
- Inline Toolbar

## Built-in plugins

- AutoFormat
- Bold
- Essentials
- FontBackgrounColor
- FontColor
- Heading
- HorizontalLine
- Image
- ImageInsertViaUrl
- ImageResize
- Italic
- Link
- List
- Math
- Paragraph
- RemoveFormat
- SpecialCharacters
- SpecialCharactersEssentials
- Strikethrough
- Subscript
- Superscript
- Table
- TableToolbar
- TaskImageUpload (enabled when `taskImageUpload` is configured)
- WordCount

Note: The included image plugins support image insertion via URL. The `TaskImageUpload` plugin provides a toolbar button for applications that supply a `taskImageUpload` callback.

## Supported languages

- de
- en
- es
- uk
